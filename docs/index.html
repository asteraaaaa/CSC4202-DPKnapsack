📚 CSC4202 – DP Knapsack Portfolio

This project solves the classic 0/1 Knapsack Problem using the Dynamic Programming (Bottom-Up) approach.

💡 Problem Statement

Given weights and values of n items, put these items in a knapsack of capacity W to get the maximum total value.

🧠 DP Solution

  • Time Complexity: O(nW)
  • Space Complexity: O(nW)
  • Approach: Bottom-Up Table Filling

💻 Java Code

Below is a simplified version of my code:

public class DPSolver { public static int knapsack(int W, int[] wt, int[] val, int n) { int[][] dp = new int[n+1][W+1]; for (int i = 1; i <= n; i++) { for (int w = 0; w <= W; w++) { if (wt[i-1] <= w) dp[i][w] = Math.max(val[i-1] + dp[i-1][w - wt[i-1]], dp[i-1][w]); else dp[i][w] = dp[i-1][w]; } } return dp[n][W]; } }
