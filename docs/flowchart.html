0/1 Knapsack Flowchart

Start
↓
Read number of items (n)
For each item: name[i], weight[i], value[i]
Read boat's weight limit (W)
↓
Create dp[n+1][W+1]
Initialize all dp[i][w] = 0
↓
Set i = 1, w = 0
↓
If i ≤ n
True
If w ≤ W
True
If weight[i] ≤ w
True
dp[i][w] = max(dp[i-1][w], value[i] + dp[i-1][w - weight[i]])
False
dp[i][w] = dp[i-1][w]
↓
Print dp[n][W] as max value
↓
Set i = n, w = W
↓
If dp[i][w] ≠ dp[i-1][w]
True
Item i is selected
False
Item i is not selected
↓
w = w - weight[i]
↓
Print item name, weight, value
↓
Stop
